# 广州塔 · 3D 交互场景 | Canton Tower 3D

用 Three.js 程序化建模的广州塔（小蛮腰）交互网页：单叶双曲面钢架结构、珠江、周边建筑群，支持拖拽漫游、昼夜切换与灯光秀。

**在线体验**：开启 GitHub Pages 后访问 `https://<你的用户名>.github.io/canton-tower-3d/`

## 功能

- **广州塔建模**：按单叶双曲面数学曲线生成塔身，40 层环梁 + 24 根立柱 + 斜撑组成螺旋钢架，腰线、观光平台、天线一应俱全
- **周边场景**：珠江（流动水面 + 跨江大桥）、程序化生成的建筑群（夜晚亮窗）、塔下裙楼
- **拖拽漫游**：左键拖动旋转、滚轮缩放、右键平移，带阻尼；也支持手机触屏
- **昼夜场景**：白天 / 黄昏 / 夜晚一键切换（天空、雾效、灯光、星空平滑过渡）
- **灯光秀**：彩虹流光 / 海洋 / 烈焰 / 自定义颜色 / 关闭，辉光强度可调
- **预设机位**：珠江夜游、云端俯瞰、塔底仰望，一键飞过去
- **更多调节**：自动旋转及速度、建筑灯光、雾效开关、视角重置

## 本地运行

直接用浏览器打开 `index.html` 即可（需要联网加载 Three.js CDN）。

## 技术

- Three.js r160（ES Module + importmap）
- UnrealBloomPass 辉光后期
- Canvas 程序化纹理（建筑窗户、地面、江面）
- 零构建，单文件
